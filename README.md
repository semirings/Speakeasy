# Speakeasy

A friendly, HyperTalk-inspired language and runtime, written in Dart.

> Status: early scaffold. There is no language implementation yet.

## Setup

```bash
dart pub get
dart analyze
dart test
dart run bin/speakeasy.dart
```

## Layout

```
bin/speakeasy.dart     command-line entry point (stub)
lib/speakeasy.dart     public library
lib/src/               implementation
test/                  tests
```
